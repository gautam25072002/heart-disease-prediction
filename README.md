# ***Hear Disease Prediction Using Machine Learning***

# Overview

This project is a machine learning web application that predicts the likeliehood of heart disease based on user-provided health parameters. The application uses Streamlit to provide an interactive user interface.

# Features

- Interactive Streamlit user interface
- Machine learning based prediction
- User input for relevant health parameters
- Prediction results displayed through the web application

# Tech Stack

- Python
- Machine Learning
- Scikit-learn
- Pandas and Numpy
- Streamlit
